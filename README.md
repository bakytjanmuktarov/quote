# Генератор случайных цитат
Простой сайт который показывает случайную цитату и её автора. Надо нажать на кнопку и будет новая.
Внешний вид сделан по макету моему же макеты в figma.

## Возможности
Загрузка случайной цитаты из публичного API
Отображение текста и имени автора
Кнопка для получения новой цитаты
Цитата загружается автоматически при открытии страницы
Плавное появление карточки с цитатой
Эффект при наведении на кнопку

## Что я использовал
HTML
CSS (flexbox, transitions)
JavaScript (fetch, async/await)
[DummyJSON Quotes API](https://dummyjson.com/docs/quotes) 

## API
В проекте используется бесплатное API DummyJSON:
GET https://dummyjson.com/quotes/random
Пример ответа:
"id": 42,
"quote": "Many a good hanging prevents a bad marriage.",
"author": "William Shakespeare"
Цитаты приходят на английском языке.

## Установка
скачайте проект с гитхаба и распакуйте зип файл в обычный файл, и откройте данный файл с помощью visual studio code
## Запуск
есть два варианта запуска через делей гит хаба который приклемен в ассайнменте или же через установку и лайв сервер
Для работы нужен интернет, потому что цитаты загружаются из API.
## Как это работает
При открытии страницы `app.js` отправляет запрос к API через `fetch`.
Ответ превращается в объект методом `response.json()`.
Текст цитаты и имя автора вставляются на страницу.
Карточка получает класс `visible`, и запускается анимация появления.
Каждый клик по кнопке повторяет эти же шаги.
